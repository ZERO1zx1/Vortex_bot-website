About Us

Юугаараа онцлог вэ?

ТҮЛХЭЦ

Түгээмэл асуултууд

Ботыг хэрхэн сервертээ нэмэх вэ?

“Ботыг нэмэх” товч дээр даран Discord урилгын хуудас руу ороод, нэмэх серверээ сонгоно. Менеджер эрхтэй бүртгэлээр Server Management зөвшөөрлийг идэвхжүүлэх хэрэгтэй. Бот автоматаар 44 slash командыг бүртгэдэг.

Командууд хэрхэн ашиглах вэ?

Admin ба Модерац командыг / slash байдлаар (жишээ нь /ban), бусад бүх командыг A! префиксээр (жишээ нь A!daily, A!work) ашиглана.

Мөнгөний систем хэрхэн ажилладаг вэ?

A!daily дарж өдөр бүрийн урамшуулал авах, A!work ажиллах, A!market дэлгүүрээс юм худалдаж авах, A!gamble казино тоглохоор мөнгө олж болно.

Бот 24/7 ажилладаг уу?

Тийм ээ — Supabase backend дээр heartbeat системээр ажилладаг. Энэ вэбсайтын “Ботын төлөв” хэсгээс жинхэнэ цаг хугацааны Online/Offline төлөвийг харж болно.

Өгөгдөл хадгалагддаг уу?

Тийм — Supabase (PostgreSQL) дээр 57 таблицээр хэрэглэгч, эдийн засаг, гэрлэл, түвшин гэх мэт бүх өгөгдөл бат бөх хадгалагдана. Бот унтарч асахад ч мөнгө, түвшин устахгүй.

Premium хэдийд нээгдэх вэ?

Premium систем одоогоор боловсруулагдаж байна. Бэлэн болоход Discord дамжуулан мэдэгдэх болно. Одоогоор бүх үндсэн командууд ҮНЭГҮЙ.

Алдаа гарвал хаана хэлэх вэ?

Discord дамжуулан шууд хэлэх эсвэл GitHub Issues хуудсанд бичээрэй.
